# Security

Este repositório é apenas a casca estática pública do ParasiteDX.

**Nunca commite:**
- Cloudflare API tokens;
- Account credentials;
- Streamlit Secrets;
- senhas de beta/admin;
- chaves de API de LLMs;
- dados de usuários ou casos.

Segredos pertencem ao backend/deployment secret store, não ao HTML ou JavaScript do navegador.
